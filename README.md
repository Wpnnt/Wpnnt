### About

Full-Stack Developer based in Rio de Janeiro, studying Systems Analysis and Development (ADS). I build web applications and REST APIs, and I like owning a project from the first idea to a live deployment.

My DevOps experience comes from a Proxmox homelab I maintain with friends, where I manage containers, VMs, nginx, and self-hosted services. I'm also studying cybersecurity.
